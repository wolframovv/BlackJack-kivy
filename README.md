# BlackJack (Kivy)

## Структура
```
main.py              запуск, навигация, кнопка «Назад», сохранение при сворачивании
core/                логика без Kivy (покрыта тестами)
  cards.py           Card, Deck, Hand
  round.py           один раунд: раздача, hit/stand/double/split, сдача, страховка, дилер, итоги
  storage.py         пользователи (логин и имя), аватары, блокировка на 24 часа, пароли
  i18n.py            переводы (русский/английский)
  skins.py           список скинов
  dataset.py         запись решений игрока в CSV для обучения ботов
ui/
  style.kv           стили виджетов
  theme.py           цвета, размеры, шрифт, PARTICLES_IN_GAME
  widgets.py         кнопки, панели, поле ввода, карта, круглый аватар, окно-предупреждение
  avatar_picker.py   выбор аватара из галереи (Android: системное окно; ПК: выбор файла)
  background.py      фон и движущиеся частицы
  screens/           экраны: login, menu, mode, profile, leaderboard, skins, betting, game
tools/               dataset_stats.py — проверка собранных данных
tests/               тесты ядра и сценарии интерфейса (на заглушке Kivy)
DATASET.md           описание файлов с решениями и правила для обучения
cards/  etc/         ваши картинки и шрифт; etc/default_pic.png — аватар по умолчанию
                     (если файла нет, рисуется серая фигурка человека)
```

## Запуск на ПК
    pip install kivy==2.3.0
    python main.py

На ПК окно имитирует размер ландшафтного телефона.

## Тесты
    python -m unittest discover -s tests

## Сборка
    buildozer android clean
    buildozer android debug deploy run logcat

## Игроки
- **Логин** — по нему входят; показывается в таблице лидеров мелким серым шрифтом.
- **Имя** — его видят все (таблица, игра, профиль); меняется в «Моём профиле».
- **Аватар** — круглый; выбирается из галереи, по умолчанию `etc/default_pic.png`.
- **Блокировка:** если деньги кончились, играть можно только через 24 часа, затем начисляется
  $1000. Пока блокировка есть хотя бы у одного аккаунта, нельзя создавать новые.
